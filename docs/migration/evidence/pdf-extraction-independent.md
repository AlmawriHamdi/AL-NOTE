**Text and completeness.** Independent controlled ToUnicode mappings rejected lone high/low surrogates and a high surrogate followed by an ordinary scalar. Valid supplementary U+1F600, U+10FFFF and a multi-scalar `A😀B` mapping preserved scalar values, scalar positions and geometry. Native output accepted exactly **8,192 supplementary scalars / 16,384 UTF-16 records** and rejected 8,193 without returning a prefix. Permanent tests exercise lower caller ceilings as well.

The independent rectangle oracle starts from known drawn source rectangles and applies explicit quarter-turn equations, then intersects with asymmetric requested regions. It does not use `PdfPageCoordinates` to compute expectations. All four source rotations passed for both text and internal-link bounds, including filtered full-page scalar indices. The permanent negative-origin case and empty/scanned cases also passed.

Explicit spaces, generated CR/LF and generated spaces survive full-page extraction. Actual-worker partial-region requests containing unpositioned generated separators return `unsupported`; no partial text is presented as complete. The supported output is an engine-order embedded-text projection, not reconstructed reading order or OCR.

A useful limitation surfaced during probe development: a controlled two-line **single-letter** layout yields `AB` directly from this PDFium worker, whereas a two-word layout generates `Hello\r\nworld`. Raw worker records and scalar indices proved the parent was not removing those separators. The final probe compares the complete native sequence with the parent sequence, separately asserts an explicit `A B`, and verifies the unsupported-region rule on genuinely generated separators. Earlier assumptions that every two-line layout must generate CR/LF were not retained as candidate findings. The Type3 fixture also has no mapping for an explicit space; its whole-result `unsupported` was an honest rejection, not truncation.

**Links and hostile boundaries.** Internal destinations are validated against actual worker-reported page count, with exact integer types. HTTP(S) classification requires explicit permission at both boundaries. URI buffers are length-checked before allocation, strictly decoded and freed per link; the URI itself is discarded before the public result. Worker calls only query APIs, never activation/navigation APIs. Forbidden/malformed primary actions reject the entire extraction; this is not an action-graph sanitizer.

Independent real-host malicious responses covered extra secret-bearing fields, floating and out-of-document destinations, reversed/empty/oversized bounds, extra link fields, wrong URI type, excessive UTF-8 URI bytes and JavaScript URI metadata. They rejected with redacted errors. Controlled workers additionally exercised valid-looking output followed by hangs, closed output, stderr overflow, pre-ready exit and closed input; valid recovery followed. Existing tests independently covered incomplete transmission, truncation, oversized/excess frames, crashes/nonzero exits, false completeness, surrogate records and surviving descendants.
